# AI Scan 🤖 / 📷

**Нативное Android-приложение** — платформа-детектор ИИ-контента. Анализирует **фото, видео и аудио** и отвечает на вопрос: материал создан/обработан искусственным интеллектом или снят (записан) человеком без ИИ-обработки.

> Не веб-обёртка: полноценное нативное приложение (React Native + собственные Kotlin-модули), весь анализ выполняется **на устройстве**, ничего не отправляется в сеть.

## Возможности

| | |
|---|---|
| 🖼️ **Фото** | EXIF (камера/ПО/GPS), поиск подписей генераторов в XMP/PNG-тексте, размеры кадра, статистика зерна, 2D-Фурье: пол высоких частот и периодические артефакты, плотность краёв, «пластиковая» кожа |
| 🎬 **Видео** | Сигнатура контейнера (аппаратный кодек телефона vs Lavf/Sora/Runway…), извлечение кадров и прогон их через фото-анализ, стабильность зерна между кадрами, разбор звуковой дорожки |
| 🎵 **Аудио** | Шумовой фон (живая запись ≠ «цифровая тишина»), жёсткий обрез спектра 15–17 кГц (нейро-вокодеры), стационарность ВЧ-шума, микродинамика, псевдо-стерео, ID3/Vorbis-теги (Suno, Udio, ElevenLabs…) |
| 🧾 **Отчёт** | Вердикт с уверенностью, каждый признак — с измеренным значением и объяснением «почему это важно», текстовый отчёт для отправки через «Поделиться» |
| 🕘 **История** | Локальное хранение проверок (AsyncStorage), повторный просмотр результатов |

## Вердикты

* 🤖 **Создано или обработано ИИ** — перевес признаков генерации
* 📷 **Создано человеком** — признаки живой съёмки/записи, ИИ не найден
* 🔀 **Смешано** — сильные сигналы с обеих сторон (снимок человека, обработанный нейросетью)
* ❓ **Недостаточно данных** — сигналы слабы или противоречат друг другу

Оценка **вероятностная** (эвристика + DSP), это инструмент первой линии проверки, а не судебная экспертиза.

## Техническая архитектура

```
src/core/            — движок анализа (чистый TypeScript, покрыт Jest-тестами)
  imageAnalysis.ts   — шум, Фурье, артефакты, EXIF/размеры
  audioAnalysis.ts   — спектр, тишина, динамика, вокодерные обрезы
  videoAnalysis.ts   — контейнер + агрегация кадров + звук
  scoring.ts         — взвешивание признаков → вердикт/уверенность
  report.ts          — текстовый отчёт
src/ui/              — экраны приложения (тёмная тема, RU)
src/native/          — обёртка нативного модуля
android/.../NativeMediaModule.kt — EXIF/кропы, кадры видео, MediaCodec-декодер аудио
```

## Разработка

```bash
npm ci
npm test          # юнит-тесты движка
npx tsc --noEmit  # типы
npx eslint .      # линт
npm run android   # сборка на устройстве (нужен Android SDK)
```

Сборка APK происходит в GitHub Actions при каждом пуше: см. `.github/workflows/build-apk.yml`. После сборки релиз автоматически публикуется с прямой ссылкой на APK.

## Методика (кратко)

1. **Метаданные/контейнер** — прямые метки генераторов и камер.
2. **Статистика шума** — камера даёт зерно, генерация даёт аномально чистые поля.
3. **Спектр (Фурье)** — «пустой» высокочастотный пол, периодические решётки апскейлеров; для звука — обрезы 15–17 кГц и стационарный шум вокодеров.
4. **Сквозные проверки видео** — стабильность зерна между кадрами.
5. Признаки взвешиваются; сильные метаданные и пиксельные/спектральные подтверждения дают наивысшую уверенность.
